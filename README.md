# CSE 110 Programming Contests

Problem statements and Python solutions for two programming contests from the CSE 110 course.

## Contents

The `Programming Contest/` folder contains:

| File | Description |
|---|---|
| `PROGRAMMING CONTEST #1.pdf` | Problem statements for contest 1 |
| `programming_contest(battlestar_galactica).py` | Python solution for contest 1 |
| `PROGRAMMING CONTEST #2.pdf` | Problem statements for contest 2 |
| `programming_contest_2_(battlestar_galactica).py` | Python solution for contest 2 |

## Run

Requires Python 3.

```bash
python "Programming Contest/programming_contest(battlestar_galactica).py"
```
